## **Bite & Dine**

**Bite & Dine** is a Restaurant Table Management System designed to simplify the process of managing restaurant tables and assigning them to guests efficiently.

This project is developed by a group of second-year Information Technology students from STI College Kalibo as part of an academic requirement.

## **About the Project**
The system aims to provide a simple and convenient way for restaurant staff, particularly hosts and hostesses, to manage table availability, guest assignments, and restaurant seating.
